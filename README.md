# ukg-wfm-ai-agent
UKG WFM AI Agent

Agent Capabilities 
1- Find the Co-worker info
2- Check the timecard signoff status 
3- Get the list of Co-worker who are not signed off.
4- Find Co-worker timecard info - like particualy date, week. 




Example user questions:

```Show me John Smith's timecard for this week.
Which employees in hyperfind 12345 have missed punches today?
Get people details for employee ID 456789.
```
